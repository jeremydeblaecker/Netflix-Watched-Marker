# Installation Firefox — Netflix Watched Marker

1. Décompresser l’archive.
2. Ouvrir `about:debugging#/runtime/this-firefox`.
3. Cliquer sur **Charger un module complémentaire temporaire…**.
4. Sélectionner `manifest.json`.
5. Ouvrir Netflix puis recharger la page avec `Ctrl + F5`.

L’installation temporaire disparaît au redémarrage de Firefox. Une installation permanente nécessite une signature Mozilla.
