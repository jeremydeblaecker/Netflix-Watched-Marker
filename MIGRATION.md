# Migration des données

Cette version conserve l’identifiant Firefox historique de l’extension. Remplace les fichiers de l’ancien dossier, puis clique sur **Recharger** dans `about:debugging`. N’utilise pas **Supprimer**.

Ouvre ensuite le popup et clique sur **Exporter vers Streaming Watched Manager**. Importe le JSON obtenu depuis l’extension unifiée.
